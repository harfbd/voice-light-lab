# 聲光實驗室｜語音辨識好好玩

[開啟教學網站](https://harfbd.github.io/voice-light-lab/)

以聲音取樣實驗、語音辨識流程、燈光指令模擬、IQ 燈實作與六題小挑戰，探索聲音、AI 與手作。

中文為主，附可切換的英文輔助。原教材與照片由麥寮高中林雲龍老師提供，補充資料來源列於網站各單元。

網站採用 HTML、CSS 與 JavaScript。所有圖片位於 `assets/`，可直接開啟 `index.html`，或透過靜態網站伺服器預覽。GitHub Pages 使用 `main` 分支根目錄發布。

麥克風語音辨識需瀏覽器支援、HTTPS 與使用者授權。網頁同時提供按鈕及文字指令操作。
